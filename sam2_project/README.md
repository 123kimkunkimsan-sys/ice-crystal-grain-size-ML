# SAM2ボックス精緻化候補ブランチ(骨組みのみ)

## これは何か

他の2候補(Cellpose、StarDist)は「YOLOによる検出そのものを置き換える」大がかりな案だが、
こちらはもっと小さい一手。**YOLOの検出(ボックス)はそのまま使い、各ボックスをSAM2に
「このへんを見て」とプロンプトとして渡し、結晶のピクセル単位マスクだけを取り出す**。
ResNetの回帰をやめて、マスク面積から直接円相当径を計算する。

学習データなし・追加学習なしで今すぐ試せる「最小の一手」という位置づけ。

## なぜこれを候補に入れたか

- Segment Anything (Kirillov et al., 2023, ICCV, https://arxiv.org/abs/2304.02643) および
  その後継のSAM2は、**ボックスをプロンプトとして渡すと、その中の物体のセグメンテーション
  マスクをゼロショット(追加学習なし)で返す**ことができる。
- 微小粒子へのSAM系モデルの応用例:
  - NP-SAM (ナノ粒子, 電子顕微鏡): https://www.cambridge.org/engage/coe/article-details/6463c10aa32ceeff2dc08c49
    重なり合う粒子の扱いに関する手法も提案されている。
  - SAM4EM (Goel et al., arXiv:2501.03153): 低温電子顕微鏡の粒子追跡にSAM2を
    プロンプトベースでゼロショット適用し、既存手法を大きく上回る精度を報告。
  - SAM-I-Am (Abebe et al., arXiv:2404.06638): 電子顕微鏡の組織セグメンテーションに
    SAMを応用、素のSAMに対して大きな改善を報告。
  これらはいずれも電子顕微鏡が中心で、本研究の光学顕微鏡の氷結晶とは条件が異なる点に注意
  (そのままでは精度が出ない可能性があり、検証が必要)。

## 既存パイプラインとの関係(統合イメージ)

```
[元画像] → YOLOv8検出(そのまま流用) → 各ボックスをSAM2にプロンプト →
結晶マスク → マスク面積から円相当径を直接計算(ResNet不要)
```

- **既存のYOLO検出欠失(大型・複雑結晶の見逃し)はこの案では直らない。** あくまで
  「検出できたボックスの精度」を上げるだけなので、③パイプライン全体・④k値の
  根本改善にはならない可能性が高い。ただし、②ResNet単体相当の精度向上(ボックスが
  緩くても正確な面積が取れる)は期待でき、しかも学習データなしで試せるのが利点。
- Cellpose/StarDistの本格導入までの「つなぎ」、または検出精度向上(別課題)と
  組み合わせる前提の一手として位置づけるのが妥当。

## 未解決の課題(要検討)

- SAM2のモデルサイズ・推論速度(RTX 3060 12GBで現実的な速度が出るか要確認)。
- 光学顕微鏡・氷結晶という、SAM系の実績が少ない領域でどこまで精度が出るか未検証。
  まずは数枚の画像で目視確認してから本格導入を判断すべき。
- ゼロショットで不十分な場合、少数のマスクで軽く追加学習(fine-tune)する選択肢もある。
